My Hobby: Building Things

One of my favourite things to do in my free time is building small projects. I like trying out new ideas and seeing if I can actually make them work.

Why I Like This Hobby

I started getting interested in building projects because I like computers and technology. Sometimes the project works on the first try and sometimes it doesn't, but fixing the problems is also fun.

Things Needed For My Projects

  • Laptop
  • Arduino board

  • Breadboard
  • USB cable

How I Usually Start A Project

  1. Think of an idea
  2. Search about it
  3. Collect the things I need
  4. Make a basic version
  5. Test it
  6. Fix the problems
